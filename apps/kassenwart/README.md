# Kassenwart & Prüf-App

Dieser Ordner ist für die geplante Prüf- und Freigabe-App des Kassenwarts bzw. Vorstands reserviert.
Hier werden Funktionen gebündelt zum:
- Automatisierten Einlesen und Validieren der exportierten Abrechnungs-PDFs (`data/export/*.pdf`)
- Prüfen von Beleganhängen und Ausfüllen der digitalen Kassenwart-Felder (Überweisungsdatum, Buchungsvermerk)
- Sammel-Export / SEPA-XML Generierung für die Bank
